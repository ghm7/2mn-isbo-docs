## Estructuras de control 'for'

La estructura 'for' se utiliza para iterar, es decir, repetir un bloque de
comandos varias veces

```bash
for i in {1..5}; do
    echo "hola $i"
done
```

Cómo controlo la cantidad de repeticiones?

La cantidad de repeticiones depende del tamaño de conjunto que se recorre

```bash
for entrada in {todas mis entradas}; do
  entregar $entrada
  subir al juego
  ...
  bajar del juego
done
```

```bash
# iterar un rango
i in {1..5}
i in {a..w}
```

```bash
# iterar sobre nombres de archivos y directorios
i in D* # tomará nombres que comiencen con "D"
```

```bash
# iterar sobre la salida en pantalla de un comando
i in $(ls)
```

```bash
#!/bin/bash

for i in {1..7}; do
  echo "lo hago $i"
done
tree
```

```bash
#!/bin/bash

for ((i=1; i<=5; i++))
do
  cuadrado=$((i*i))
  echo "iteracion de $i: El cuadrado de $i es $cuadrado"
done
```

1. Inicializador del iterador `i=1`
2. Condición `i<=5`
3. Actualización en cada bucle `i++`
