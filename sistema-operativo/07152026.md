# Ejercicios de scripting

## Ejercicio 1

Realizar un script que pueda armar toda la siguiente estructura:

```text
ONU
  - America
    - Norte
      - USA
    - Sur
      - Ecuador
    - Central
      - Nicaragua
  - Europa
    - Francia
  - Asia
    - China
```

- Al final del script agregar un comentario con autores
- Usar el comando `echo` para indicar el "El trabajo ha terminado" y guardar
  como `eje1.sh`

### Solución 1

```bash
#!/bin/bash

echo "Creando America del Norte..."
mkdir -p ONU/America/Norte/USA

echo "Creando America del Sur..."
mkdir -p ONU/America/Sur/Ecuador

echo "Creando America Central..."
mkdir -p ONU/America/Central/Nicaragua

echo "Creando Europa..."
mkdir -p ONU/Europa/Francia

echo "Creando Asia..."
mkdir -p ONU/Asia/China

echo "Gabriel Pozzi"
```

### Solución 2

```bash
#!/bin/bash

folders=(
  "ONU"
  "ONU/America"
  "ONU/America/Norte"
  "ONU/America/Norte/USA"
  "ONU/America/Sur"
  "ONU/America/Sur/Ecuador"
  "ONU/America/Central"
  "ONU/America/Central/Nicaragua"
  "ONU/Europa"
  "ONU/Europa/Francia"
  "ONU/Asia"
  "ONU/Asia/China"
)

for folder in "${folders[@]}"; do
  echo "Creando... $folder"
  mkdir -p "$folder"
done

echo "Gabriel Pozzi"
```

## Ejercicio 2

```text
FIFA
  - EUFA
    - RFEF
  - Conmebol
    - AUF
  - Concacaf
    - FMF
  - CAF
    - EFA
  - AFC
    - JFA
  - OFC
    - NZF
```

Realizar la siguiente estructura con un script llamado: `eje2.sh`

Una vez completado:

1. Renombrar `AUF` por `FPF`
2. Renombrar `NZF` por `FTF`
3. Crear el siguiente archivo en `FIFA`: `copasmundiales.txt`
4. Copiar `copasmundiales.txt` a `RFEF`
5. Indicar con `echo` la finalización

### Solución

```bash
#!/bin/bash

mkdir -p FIFA/EUFA/RFEF
mkdir -p FIFA/Conmebol/AUF
mkdir -p FIFA/Concacaf/FMF
mkdir -p FIFA/CAF/EFA
mkdir -p FIFA/AFC/JFA
mkdir -p FIFA/OFC/NFZ

tree FIFA

mv FIFA/Conmebol/AUF FIFA/Conmebol/FPF
mv FIFA/OFC/NFZ FIFA/OFC/FTF

touch FIFA/copasmundiales.txt

cp FIFA/copasmundiales.txt FIFA/EUFA/RFEF

echo "Gabriel Pozzi"

tree FIFA
```

## Comandos básico de información y ayuda

En GNU/Linux podemos solicitar información al sistema sobre: manuales,
identificación de usuarios, versiones del sistema, revisiones de fecha. Estos
comandos por si mismos no modifican nada, por ello, podemos practicarlos sin
miedo:w

### man

El comando `man` se utiliza para acceder a los manuales detallados de comandos,
programas, funciones y configuraciones del sistema

### whoami

Da a conocer el nombre del usuario actual

### info

Se utiliza para acceder a documentación detallada de comandos, programas o
bibliotecas, formalizado en forma hipertextual

### help

El comando `help` se utiliza para tener información breve sobre comandos
internos del shell, es decir, aquellos integrados en el shell y no programas
externos

### file

El comando `file` analiza archivos y determina su tipo basándose en su
contenido, no solo en la extensión. Es útil para identificar archivos
desconocidos como binarios, scripts e imágenes

### date

Muestra o configura la hora y fecha del sistema

### cal

Sirve para ver fechas
