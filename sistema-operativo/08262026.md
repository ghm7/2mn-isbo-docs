## Comandos para gestión de memoria

Que se puede gestionar mediante común dos para manejar la memoria?

- Paginación de memoria por demanda
- Segmentación de memoria
- Memoria virtual
- Memoria de intercambio (swapping)

### fdisk

- `sudo fdisk /dev/sdb`

Crea una partición

- n -> nueva
- p -> primaria
- e -> extendida

- `sudo fdisk -l /dev/sda`

De información del disco sda y sus particiones

### mkfs

Formatea sistema de archivos en particiones

- `sudo mkfs.ext4 /dev/sda1`

Formatea la partición con el sistema de archivos `ext4`

### mkswap

Configura una partición o archivo como área de intercambio

- `sudo df -h /` >>> verificamos espacio libre
- `sudo ls th /swapfile 2>/dev/null || echo "no existe"` >>> chequear si existe
  otra swap
- `sudo fallocate -l 1G /swapfile` >>> crea un archivo swap de 1GB
- `sudo chmod 600 /swapfile` >>> configuramos permisos
- `sudo mkswap /swapfile` >>> formateo como swap
- `sudo swapon /swapfile` >>> activa el swap
- `grep -q '^/swapfile' /etc/fstab || echo '/swapfile none swap 0 0' | sudo tee -a /etc/fstab` >>>
  hace la partición permanentemente
- `swapon --show && free -h` >>> verificamos

### swapon

Activa el espacio de intercambio para su uso

- `sudo swapon /dev/sda1`

### top/htop

Monitorea procesos en tiempo real

#### top

Despliega los procesos activos e información general de CPU, RAM y SWAP

- `top`
  - `f` menu de procesos
  - `k` permite ingresar un PID
  - `b` ejecuta en modo batch, no interactivo
  - `q` sale de top

#### htop

Despliega los procesos activos e información general de CPU, RAM y SWAP

- `htop`
  - F6 -> ordena por PID, usuario, memoria virtual y estado
  - F9 -> termina proceso

### `free`

Muestra información sobre memoria RAM y swap disponible

- `sudo free -h` >>> muestra información sobre el uso de memoria RAM y de
  intercambio )swap=
- `sudo free -m` >>> muestra toda la información en formato MB
- `sudo free -t -h` >>> muestra una linea adicional con el total general
- `sudo free -s 10` >>> indica a cada cuanto debe monitorear en tiempo real
  (10s)
- `sudo free -s 10 -c4` >>> repite el comando 4 veces

### `vmstat`

Proporciona un resumen más amplio de estadística del sistema, incluyendo
memoria, CPU, procesos, entrada/salida y swap

- `vmstat -s -S M` >>> resumen detallado de estadísticas en MB
