## Preparar script

### A

1. Crear un directorio llamado `practica-cron` dentro de su directorio de
   trabajo
2. Dentro de ese directorio, crear un archivo llamado `monitoreo.sh`
3. Incorporar

```bash
#!/bin/bash

echo "fecha: $(date)">>"$HOME/practica-cron/registro.log"
df -h / >> "$HOME/practica-cron/registro.log"
echo "..............">> "$HOME/practica-cron/registro.log"
```

1. Asignar permisos de ejecución al script
2. Ejecutar el archivo manualmente y comprobar que se genere `registro.log` con
   la información correspondiente

- `crontab -l` -> lista todas las tareas creadas
- `crontab -r` -> borra todas las tareas creadas
- `crontab -e` -> borra una tarea en particular

## Tareas at

A diferencia de `cron` que programa tareas recurrentes, `at` se usa para
ejecutar algo una sola vez en un momento específico. En Debian las tareas `at`
no están instaladas.

Para ejecutar una tarea `at` hacemos lo siguiente:

```bash
at 15:30
at> ls
at> Ctrl + D [para terminar]
```

Ejemplos

```bash
at now + 5 minutes
at 14:30 tomorrow
at 09:00 Oct 30
at midnight
```

Para ver las tareas agendadas pendientes usamos `atq`. Todas las tareas `at`
tienen un ID, si yo quisiera eliminar una tarea `at`, escribo: `atrm [ID]`

1. Programar la ejecución de `monitoreo.sh` para dentro de 2 minutos, utilizando
   `at`
2. Consultar las tareas agendadas de `at`
3. Comprobar si se ejecutó en el archivo `registro.log`
4. Programar nuevamente con `at` `monitoreo.sh` para dentro de 30 minutos
5. Identificar la tarea asignada y cancelarla para su ejecución

Posibles soluciones

```bash
echo "$(PWD)/monitoreo.sh" | at now + 2 minutes
printf '"%s"\n' "$HOME/practica-cron/monitoreo.sh" | at now + 2 minutes
```

## Tareas batch

Para el caso de las tareas `batch` estas se ejecutaran cuando el sistema tenga
baja demanda de trabajo. A diferencia de las tareas `at`, no puedo marcar un
momento exacto

Las tareas `batch` no pueden ser utilizadas para trabajos urgentes

```bash
batch
at> [salimos] Ctrl + D

echo "comando" | batch

batch -f script.sh [lee comandos de un archivo]
```

Para consultar tareas agendadas es con el comando `atq`, en este caso me va a
mostrar la fecha de agendado de la tarea pero va a aparecer con una `b`
representando que es de `batch` y se va a mostrar la hora que se agenda porque
no se sabe cuando se ejecuta ya que se espera que se haga en un bajo movimiento
de la maquina.

Si quisiera consultar la hora del sistema `uptime`
