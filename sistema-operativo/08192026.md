## Comandos basicos para filtros

- grep
- tail
- head
- sort
- cut
- tr
- wc
- find
- uniq

```bash
grep "error" archivo.txt
cat archivo.txt | grep "error"
tail -n 10 acceso.txt
tail -f acceso.txt
head -n 10 acceso.txt
sort -n nombres.txt
cut -d ',' -f2 datos.csv
cut -c4- texto.txt
echo "Hola Mundo" | tr '[:lower:]' '[:upper:]'
```

> [!NOTE]
>
> 1 byte = 8 bits
>
> Hola = 4 bytes = 32 bits

### find

Herramienta poderosa y versátil utilizada para buscar archivos y directorios
tomando diferentes criterios nombres, tipos, tamaños, permisos, fecha de
modificación entre otros

```bash
find . -type f -name "*.txt"

-type f es file
-name sensible a mayúscula y minúscula
. directorio actual
```

#### Localizar archivos >1gb

`find /var -type -f -size +1gb`

#### Buscar archivos con permisos de ejecución

`find /usr/bin -type f -perm /a=x`

#### Buscar archivos temporales con extensión .tmp

`find /tmp -type f -name "*.tmp" -delete`

### uniq

Procesa líneas de texto en un archivo o entrada standard, eliminando o contando
líneas duplicadas consecutivas

`uniq lista.txt`

| Archivo original | Resultado de comando |
| ---------------- | -------------------- |
| manzana          | manzana              |
| manzana          | kiwi                 |
| kiwi             | naranja              |
| kiwi             |                      |
| naranja          |                      |

`sort lista.txt | uniq`

| Archivo original | Resultado de comando |
| ---------------- | -------------------- |
| manzana          | kiwi                 |
| kiwi             | manzana              |
| pera             | pera                 |
| manzana          |                      |

| Ana     | 25   | Ingenieria   |

-2. Usar comandos con filtro para extraer edades (segunda columna), ordenarlas
de mayor a menor y eliminar duplicados si los hubiera. Mostrar el resultado
final

```csv
Ana,25,Ingenieria
```

`cut -d "," -f2 estudiantes.csv | sort -n -r | uniq`

## Ejercicio 1

-1. Crear el archivo access.log con el contenido

```log
192.168.1.1 - - [10/Aug/2026:14:00:00] "GET /index.html" 200
172.16.0.2  - - [10/Aug/2026:14:01:00] "POST /login" 404 error
```

mostrar solo las últimas 2 condiciones y contar el total de líneas con "error"

## Ejercicio 2

-1. Generar el archivo `nombre.txt` con el siguiente contenido:

```text
ana
carlos
beatriz
david
ANA
```

-2. Convertir todos los nombres a mayúsculas y ordenar alfabéticamente
eliminando los duplicados, mostrar las 3 primeras líneas del resultado

#### Solución

`tr '[:lower:]' '[:upper:]' < nombres.txt | sort | uniq | head -n 3`

## Ejercicio 3

-1. Crear el archivo `datos.csv` con el siguiente contenido

```csv
Juan;  28;     Economía
María;     25;    Física
Juan;    28;    Economía
Pedro;    32;    Historia
```

-2. Reemplazar punto y coma por comas reducir espacios múltiples a uno solo,
ordenar por la tercera columna )carrera= y eliminar duplicados. Mostrar
resultados

#### Solución

`tr ';' ',' < datos.csv | tr -s " " | sort -t ',' -k3 | uniq`

## Comandos de manejo de memoria

- fdisk
- mkfs
- mkswap
- swapon
- top/htop
- free
- vmstat

La gestión de memoria en sistemas operativos como Linux se optimiza mediante
técnicas y comandos específicos

Qué se puede gestionar mediante comandos para manejar memoria?

- **Paginación es memoria por demanda:** es una técnica donde las páginas de
  memoria se cargan en RAM solo cuando se necesitan, optimizando el uso de
  recursos
- **Segmentación de memoria:** divide la memoria en segmentos de tamaño
  variable, según las necesidades del programa
- **Memoria virtual:** abstracción que permite a los procesos usar mas memoria
  de la física disponible, utilizando almacenamiento de disco como extensión
- **Memoria de intercambio:** proceso de mover datos entre RAM y disco (swap)
  para liberar memoria física cuando es escaza
