## whereis

Localiza los archivos binarios, manuales y fuentes de un comando o programa

## apropos

Busca comandos y sus descripciones en las paginas de manual basándose en una
palabra clave. Es útil para saber que comando están relacionados

## uname

Muestra información del sistema, como el nombre del kernel, version,
arquitectura o tipo de sistema operativo

## users

Aparecen usuarios de Linux con sesiones activas en el sistema

## history

Muestra todo el historial de comandos desde la primera instalación

> [!NOTE]
>
> LVM >>> es mezclar dos discos en uno

## which

Te dice la ubicación del binario del comando / app

```bash
which nvim
```

## whatis

Muestra una descripción corta de un comando, función o archivo de sistema,
extraída directamente de los manuales (`man`)

```bash
whatis cp
```

## type

Determina como se interpeta el comando e identifica:

- si es interno (`cd`)
- si es externo
- si es un alias
- si es una función

Si escribimos `type -a echo` nos va a decir todo sin alias ni funciones

```bash
type -a echo
echo is a shell builtin
echo is /usr/bin/echo
echo is /bin/echo

type echo
echo is a shell builtin
```

## Ejercicio 1

Se necesita realizar un reporte del sistema con un script llamado
`diagnosticar.sh`

Necesitamos un diagnostico rápido con información valiosa del sistema.

Se necesita:

1. Nombre de usuario que ejecuta el script
2. Fecha y hora actual
3. Nombre y version del Kernel en uso
4. Arquitectura del sistema operativo
5. Usuarios con sesión activa en el sistema
6. Terminar con el mensaje "El script ha terminado"

## Ejercicio 2

Necesitamos crear un script llamado `buscador.sh` que pueda recibir un comando
como parámetro, ejemplo: `./buscador.sh cp` y muestre toda la información
completa de ese comando

1. Información sobre que tipo de comando es (interno, externo), para eso usamos
   `type`
2. Descripción corta con el uso de `whatis`
3. La ubicación de sus binarios y manuales con el comando `whereis`
4. Finalizar con un `echo` el script

## Como leemos una variable en `shell script`

Para leer una variable, utilizamos `read variable`

Ejemplo `comando=$1`

Esto pausa la ejecución del script hasta que el usuario escriba y presione
enter, inmediatamente se guarda el texto en la variable indicada para ser
utilizada
