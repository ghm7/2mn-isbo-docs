# Comandos

## Comandos para navegación

- pwd -> Print Working Directory / Imprimir el directorio actual
- cd -> Change Directory / Permite moverte de un directorio a otro
- ls -> List / Imprime la lista de archivos en el directorio actual
- tree -> Imprime lista de archivos en forma de árbol

## Comandos para manipulación de archivos

- mkdir -> Make Directory / Crea directorio
- rmdir -> Remove Directory / Elimina directorio vacío
- cp -> Copy Directory / Copia directory
- mv -> Move / Mueve un archivo o directorio
- rm -> Remove / Elimina un archivo o directorio con los parámetros correctos

## Ruta de directorio

Una ruta de directorio es la dirección que indica la ubicación exacta de un
archivo o carpeta dentro del sistema de archivos. Funciona como una secuencia de
carpetas separadas por un delimitador

- `\` -> Contra barra Windows
- `/` -> Barra GNU/Linux

### Ruta absoluta

Especifica la ubicación completa de un archivo o directorio desde la raíz del
sistema de archivos.

### Ruta relativa

Especifica la ubicación de un archivo o directorio en relación al directorio de
trabajo actual. No comienza con barra `/` (raíz)

## Comodines

Los comodines en Linux son caracteres especiales que el shell Bash interpreta
para representar uno o varios caracteres en nombres de carpetas y directorio.

- - coincide con cualquier cadena de caracteres
- ? coincide con cualquier espacio individual
- [] coincide con cualquier carácter dentro de los caracteres

```bash
ls *.txt lista todos los archivos que terminen en .txt en el directorio actual
ls -l nota?.txt lista todos los archivos que coniciden con el patron: nota1.txt nota2.txt notaa.txt
ls -l nota[1a2J] lista solo los que coinciden con el patron de los caracteres nota1.txt nota.txt nota2.txt notaj.txt
```

## Expresiones regulares

Las expresiones regulares en Linux son patrones de texto utilizados con comandos
como `grep`, `sed` y `awk` para buscar y manipular cadena de caracteres.

> [!NOTE]
>
> grep -> Global Regular Expression Print

```bash
grep "hola" archivo.txt -> retorna la linea que tenga hola
grep "^hola" archivo.txt -> retorna la linea que empiece con hola
grep "hola$" archivo.txt -> retorna la linea que termine con hola
grep "h*la" archivo.txt -> retorna todos los strings que empiecen con h y terminen con la

sed 's/hola/chau' archivo.txt -> reemplaza la primera vez que encuentre hola por chau
sed 's/hola/chau/g' archivo.txt -> reemplaza todos los hola por chau que tenga el archivo
sed '/^#/d' archivo.txt -> borra todas las lineas que empiecen con \# del archivo

awk '{print $1}' archivo.txt -> imprime la primer columna de todas las filas del archivo
awk '{print $1, $3}' archivo.txt -> imprime la primera y la tercer columna
awk '/hola/ {print}' archivo.txt -> imprime la linea que contenga la palabra hola
```
