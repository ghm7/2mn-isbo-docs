## Until

La estructura `until` es un tipo de bucle en `bash` que ejecuta una condición
mientras sea `falsa` es decir, hasta que la condición sea verdadera. Es como el
"hermano inverso" de `while`: en lugar de repetir "mientras si", repite "hasta
que no"

```bash
until [ condicion ]; do
  # codigo a ejecutar
done
```

## Cron

Cron es un servicio de Linux que ejecuta comandos o scripts automáticamente
según un horario. Resulta útil para tareas repetitivos, por ejemplo, generar
respaldos, limpiar archivos temporales o producir reportes

| minuto | hora | dia-del-mes | mes | dia-de-la-semana | comando          |
| ------ | ---- | ----------- | --- | ---------------- | ---------------- |
| 0      | 2    | \*          | \*  | \*               | /home/usuario/yo |

| campo            | valores habituales | significado          |
| ---------------- | ------------------ | -------------------- |
| minuto           | 0 a 59             | minuto de ejecución  |
| hora             | 0 a 23             | hora de formato 24hs |
| dia del mes      | 1 a 31             | dia del mes          |
| mes              | 1 a 12             | mes del año          |
| dia de la semana | 0 a 7              | domingo a sabado     |
| comando          | ruta o argumento   | lo que se ejecutará  |

### Administrar tareas programadas

```bash
crontab -e # editor del usuario
crontab -l # listar tareas existentes
systemctl status cron # consultar servicio Debian / Ubuntu
systemctl status crond # consultar servicios de otras distros / Fedora
```

#### Crea script

`nano "$HOME/respaldos.sh"`

```bash
#!/bin/bash

ORIGEN = "$HOME/cosas"
DESTINO = "$HOME/respaldos"
FECHA = $(date + "%y-%m-%d_%H-%S")
ARCHIVO = "respaldoso_${FECHA}.tar.gz"

# crea carpeta de destino si no existe
mkdir -p "$DESTINO"

# comprobar
if [ ! -d "$ORIGEN" ]; then
  echo "Error: no existe la carpeta $ORIGEN">&2
  exit 1
fi

if tar -czf "$DESTINO/$ARCHIVO" -C "$HOME" cosas; then
  echo "respaldo hecho: $DESTINO/$ARCHIVO"
else
  echo "Error al generar respaldo">&2
  exit 1
fi
```
