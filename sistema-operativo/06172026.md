# Permisos en Linux

## Que es un permiso en Linux

Un permiso en Linux es básicamente aquellas acciones en las cuales un usuario
tiene derecho a implementar. Estas acciones las podemos resumir en tres: leer,
escribir, ejecutar, sobre archivos y directorios. Las categorías son 3:
propietario, grupo y otros. La notación es `rwx` (lectura, escritura y
ejecución) o los valores numéricos son del 0 al 7, gestionado por el comando
`chmod`.

Los grupos son conjuntos de usuarios que comparte ciertos permisos y recursos.
Esto facilita la administración de permisos, ya que en lugar de asignar permisos
a cada usuario individualmente, se pueden asignar permisos a un grupo y todos
los usuarios de ese grupo heredan permisos.

Los valores de permisos son los siguientes, el total de 8 combinaciones por eso
se dice que es `octenal`

```bash
r = 4
w = 2
x = 1
```

`chmod 777 archivo` -> le estamos dando permisos totales a todos los usuarios

```bash
chmod 750 archivo -> rwx r-x ---
chmod 110 archivo -> --x --x ---
```

## Comandos de usuarios

- `useradd`: Crea un nuevo usuario con los permisos de administrador / root.
- `userdel`: Elimina usuarios.
- `usermod`: Modifica la información de un usuario.
- `passwd`: Cambia la contraseña de un usuario.
- `groupadd`: Crea un nuevo grupo.
- `groupdel`: Elimina un grupo.
- `groupmod`: Modifica la información de un grupo.

> [!NOTE]
>
> En el prompt de una terminal nosotros podemos encontrar `#` que significa que
> este usuario es root / administrador si aparece `$` es un usuario normal

## Cambiar el directorio de un usuario

```bash
mkdir -p /var/www/html/cambio
usermod -m -d /var/www/html/cambio jaime -> con el modificador -m lleva todos los archivos

# otorgar permisos sobre el directorio
chown -R jaime:jaime /var/www/html/cambio -> la -R es recursivo
chmod -R 700 /var/www/html/cambio -> solo el usuario Jaive tendra privilegios sobre el directorio
```

> [!NOTE]
>
> `chown` Comando `change owner` cambiar propietario

## Ejercicios

### Ejercicio A - Crear el grupo desarrollo

- Crear un nuevo usuario llamado "programador"
- Asignarlo al grupo "desarrollo"

#### Solución

```bash
sudo useradd programador
sudo groupadd desarrollo
sudo useradd -m -g desarrollo programador
```

- `-m` -> con todos su directorio
- `-g` -> el grupo

### Ejercicio B - Modificamos al programador

El usuario programador necesita ingresar su celular como dato nuevamente. Además
cambiar su clave de usuario a `programador`.
