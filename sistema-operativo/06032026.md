# Ejercicio clase 06032026

1. Crear los siguientes archivos en actions: mario.txt, cars.txt,
   DonKey_Kong.txt, usando rutas absolutas

2. Crear los siguientes archivos en estrategia: age_of_empires.txt,
   stronghold.txt, 0ad.txt, usando rutas relativas

3. Retrocede al directorio juegos y crear fifa.txt

4. Mover fifa.txt a deportes utilizando rutas absolutas

## Solución

```bash
pwd # Verificamos que nos encontramos en /home/usuario

# Craemos estructura base para el ejercicio
mkdir -p ~/juegos/{actions,deportes,shotgun,estrategia.jpg}

# Ejercicio 1
touch ~/juegos/actions/{Mario.txt,Cars.txt,DonKey_Kong.txt}

# Ejercicio 2
cd juegos/estrategia.jpg
touch age_of_empires.txt stronghold.txt 0ad.txt

# Ejercicio 3
cd .. && touch fifa.txt

# Ejercicio 4
mv ~/juegos/fifa.txt ~/juegos/deportes/fifa.txt
```

> [!NOTE]
>
> `mkdir -p` >> el `-p` es un _modificador_, no un parametro
> `mkdir -p ~/juegos/{actions,deportes,shotgun,estrategia.jpg}` >> lo que viene
> después del `-p` es un _parametro_

## Uso de empaquetadores en Linux

Un archivo `.tar` en Linux es un formato que agrupa múltiples archivos y
directorios en un solo punto, conocidos como `tarball`. La extensión `.tar`
proviene de `tape archive`. No comprime los datos, solo los empaqueta, aunque
suele combinarse con herramientas de compresión.

```bash
tar -cvf archivo.tar o directorio de archivos >>> empaquetar
    -c crea un nuevo archivo
    -v muestra archivos procesados
    -f especifica el nombre del archivo

tar -xvf archivo.tar >>> desempaquetar
    -x extrae archivos
```

### `.tar`

No comprime, solo archiva, agrupa archivos y directorios sin reducir su tamaño.

- _Ventajas_: preservar permisos y estructuras de directorios y archivos en
  sistemas Linux

### `.zip`

Archiva y comprime, reduce el tamaño usando algoritmos como `deflate`, se
comprime con `zip` y se descomprime con `unzip`

- _Ventajas_: es compatible en Linux, MacOS y Windows
- _Desventajas_: menor compresión que el `.rar`, no siempre preserva permisos

### `.rar`

Archiva y comprime pero usa un algoritmo propietario más eficiente que el `.zip`

### `.tgz`

Un archivo `.tgz` es un archivo `.tar` comprimido con `gzip` y es equivalente a
`.tar.gz`

Combina el archivo de `.tar` (agrupa directorios) con la compresión de `gzip`
para reducir el tamaño, que preserva permisos, estructura de directorios y
metadatos en sistemas de tipo UNIX.

Los `metadatos` son los datos que describen a otros datos, proporcionando
información sobre su contenido, estructura u origen. Actúan como una "etiqueta"
que facilita la organización, búsqueda y gestión de archivos.

En documentos son esos datos que nos dice quien es el autor o su fecha de
creación, en una foto nos dice su fecha, ubicación y resolución

## Ejercicio

### A

Crear la siguiente estructura con rutas absoluta

```text
practica/
        informe.docx
        script.sh
        image.jpeg
        datos.csv
        config.ini
        backup.sql
```

### B

Respaldar todo el contenido de practica en un `.tar`

### Solución

```bash
# Ejercicio A
mkdir ~/practica && touch ~/practica/{informe.docx,script.sh,image.jpeg,datos.csv,config.ini,backup.sql}

# Ejercicio B
tar -cvf ~/practica.tar ~/practica
```

## Procesos en GNU Linux

En un sistema operativo como Linux, un proceso es un programa en ejecución con
recursos asignados en tiempo real. Por eso cada vez que se abre una aplicación o
se ejecuta un comando, se crea un nuevo proceso, los procesos utilizan recursos
del sistema como CPU, GPU, RAM o Disco Duro
