# Comodines y expresiones regulares

Los comodines se pueden utilizar para referirse a varios archivos.

- \* coincide con cualquier cadena de caracteres
- ? coincide con cualquier con cualquier carácter individual
- \[ \] coincide con cualquier carácter dentro de los corchetes

```bash
ls *.txt            nota1.txt ✅
ls -l nota?.txt     notaa.txt ✅
ls -l nota[1a2J]    notam.txt ❌
```

Las expresiones regulares en Linux son patrones de texto utilizados con comandos
como `grep`, `sed` o `awk` para buscar y manipular cadenas de caracteres.

## `grep` busca patrones de texto

```bash
grep "hola" archivo.txt
grep "^hola" archivo.txt
grep "hola$" archivo.txt
```

## `sed` buscar y reemplazar

```bash
sed 's/hola/chau/' archivo.txt
sed 's/hola/chau/g' archivo.txt
sed '/^#/d' archivo.txt
```

## awk procesar texto por columnas

```bash
awk '{print $1}' archivo.txt
awk '{print $1,$3}' archivo.txt
awk '/hola/ {print}' archivo.txt
```

## CLI - Command Line Interface

```bash
ls -l
ls -a
ls -h
```

`-l -a -h` son modificadores, no parámetros

## Ejercicio en clase

- buscar la palabra 'dist' en demo.txt
- buscar y reemplazar la palabra 'dist' por 'distro' en demo.txt
- imprimir la cuarta columna del texto demo.txt

### Solución

```bash
grep "dist" demo.txt

sed 's/dist/distro/' demo.txt

awk '{print $4}' demo.txt
```

## Editores de textos en CLI

En la actualidad cualquier sistema Linux incluye por defecto dos editores de
texto: `vi` y `nano`. Escribimos el nombre del editor seguido del nombre del
archivo que vamos a crear o editar

```bash
nano prueba.txt
```

- crea el archivo
- si existe lo abre para editarlo

Posterior a ese comando la Terminal queda con el editor nano abierto.

`ctrl + o -> guardar`

`ctrl + x -> salir`
