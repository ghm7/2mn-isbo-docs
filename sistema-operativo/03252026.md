En una instalación Debian se va a requerir 2 contraseñas una es la de root y otra es la de usuario.

En el caso del usuario tendría un nivel de acceso básico, quiere decir que no podrá desinstalar nada a nivel de software, ni a nivel de hardware.

Luego se le puede dar permiso de root.

El root es super administrador y no existe nada por encima de él, es importante no caer en malas practicas como las de hacer cosas desde la sesión de root.

# Partición

Una partición de disco division lógica o segmento que funciona como unidad independiente. Permite organizar y gestionar el almacenamiento de datos, separar sistemas operativos o aislar archivos para mejorar rendimiento y la seguridad. Partición tiene su propio sistema de archivos.

Una partición primaria es una division principal en un disco duro que puede contener un sistema operativo y es necesario para arrancar el sistema. Un disco puede tener hasta 4 particiones primarias, o 3 primarias y 1 extendida.

Por su parte una partición extendida es un tipo especial de partición que no almacena datos directamente, sino que actúa como un contenedor para crear particiones lógicas. La partición extendida permite superar el limite de 4 particiones primarias en un disco.

# Partición lógica

No puede arrancar un sistema operativo directamente, pero es util para organizar y almacenar datos, es posible crear multiples particiones lógicas dentro de una partición extendida
