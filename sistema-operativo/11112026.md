## Dialog

```bash
#!/bin/bash

dialog  --title "Menu Principal" \
        --menu "Selecciona una opción: " 15 50 4 \
        1 "Mostrar fecha actual" \
        2 "Listar archivos" \
        3 "Salir" 2> /tmp/opcion_seleccionada

# Leer la opción seleccionada
opcion=$(cat /tmp/opcion_seleccionada)
rm /tmp/opcion_seleccionada

# Procesar
case $opcion in
  1)
    dialog --msgbox "La fecha es: $(date)" 10 40
    ;;
  2)
    dialog --msgbox "Archivos en el directorio: $(ls -lh | tail -n+2)" 20 60
    ;;
  3)
    dialog --msgbox "Adios!" 10 30
    exit 0
    ;;
  *)
    dialog --msgbox "Opción inválida" 10 30
    ;;
esac
```

### Ejercicio 2

Crear un script en Linux usando `dialog` que:

1. Pida al usuario ingresar su nombre en un cuadro de texto
2. Muestre un mensaje de bienvenida con el nombre ingresado del cuadro anterior
3. Termine la ejecución

```bash
#!/bin/bash

dialog --inputbox "Ingrese su nombre: " 10 30 2> /tmp/nombre_ingresado

nombre=$(cat /tmp/nombre_ingresado)
rm /tmp/nombre_ingresado

dialog --msgbox "Bienvenido $nombre!" 10 30
```

### Ejercicio 3

Escribir un script usando `dialog` que:

1. Muestre un mensaje preguntando si el usuario quiere continuar (si/no)
2. Si elige `si`, muestra un mensaje de confirmación
3. Si elige `no`, muestra un mensaje de despedida y termina el script

```bash
#!/bin/bash

dialog --yesno "Quiere continuar?" 10 30

if [ $? -eq 0 ]; then
	dialog --msgbox "Genial, seguimos" 10 30
else
	dialog --msgbox "Adiós, nos vemos" 10 30
fi
```

#### `$?`

La interrogación `$?` variable de estado de salida, donde `0` es `si` y `1` es
`no`. Y `255` es `Esc`.

### Ejercicio 4

Crear un script con `dialog` que:

1. Muestre un menú con dos opciones: ver la hora y salir
2. Si elige ver la hora, muestre la hora actual en un mensaje
3. Si elige salir, termina el script sin mostrar nada mas

```bash
#!/bin/bash

dialog  --title "Menu Principal" \
        --menu "Selecciona una opción: " 15 50 4 \
        1 "Ver la hora" \
        2 "Salir" 2> /tmp/opcion_seleccionada

# Leer la opción seleccionada
opcion=$(cat /tmp/opcion_seleccionada)
rm /tmp/opcion_seleccionada

# Procesar
case $opcion in
  1)
    dialog --msgbox "La hora es: $(date "+%H:%M:%S")" 10 40
    ;;
  2)
    dialog --msgbox "Adios!" 10 30
    exit 0
    ;;
  *)
    dialog --msgbox "Opción inválida" 10 30
    ;;
esac
```
