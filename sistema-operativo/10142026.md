## Case

```bash
case "$variable" in
  patron1)
    comandos
    ;;
  patron2)
    comandos
    ;;
  *)
    comandos_por_defecto
esac
```

### Ejercicio

```bash
#!/bin/bash
echo "===Menú de Opciones==="
echo "1) Saludar"
echo "2) Despedir"
echo "3) Salir"
read -p "Elige una opción (1-3):" opcion

case "$opcion" in
1)
  echo "Hola! Como estas?"
  ;;
2)
  echo "Adios! Hasta luego"
  ;;
3)
  echo "Saliendo del menu..."
  exit 0
  ;;
*)
  echo "Opcion invalida"
  ;;
esac
```

### Varias posibilidades en una misma opción

Dentro del `case` utilizamos `|` para indicar varias posibilidades

```bash
#!/bin/bash
read -p "Desea continuar? (s/n):" respuesta
case "$respuesta" in
  s|S)
    echo "Continuando..."
  ;;
  n|N)
    echo "Finalizando..."
  ;;
  *)
    echo "Respuesta invalido"
  ;;
esac
```

### Validación de datos

Hasta ahora suponiamos que el usuarios ingresaba correctamente los datos. Lo más
adecuado, sería que el programa pueda detectar entradas incorrectas.

Ejemplo: si pedimos un número entre 1 y 50, el usuario puede ingresar

```text
hola
200
-10
```

Descargamos `juego.txt` y renombramos a `juego.sh`

```bash
if ![[ "num1" =~ ^[0-9]+$ ]] || [[ "num1" -lt 1 ]] || [[ "num1" -gt 150 ]] then
  echo "ERROR: numero invalido para num1"
  exit 1
fi
```

`[[ "num1" =~ ^[0-9]+$ ]]`

Doble paréntesis plantea una condición en Shell-Script

`=~` comprueba si el texto coincide (expresión regular)

`^[0-9]+$`

- `^` inicio del texto
- `[0-9]` cualquier dígito entre 0 y 9
- `+` indica una o más características del tipo anterior
- `$` final del texto

#### break

El término 'break' es una palabra clave que permite salir prematuramente de un
bucle (for, while, until) o de un bloque 'case', saltando al código siguiente.
Es útil para terminar una iteración

```bash
#!/bin/bash
contador=0
while true; do
  echo "Contando: $contador"
  contador=$((contador+1))

  if [ $contador -eq 3 ]; then
    break # sale del bloque al llegar a 3
  fi
done
```

#### continue

El término 'continue' en un bucle hace que se salte el resto del código en la
iteración actual y se pase a la siguiente iteración

```bash
#!/bin/bash
contador=0
while true; do
  contador=$((contador+1))
  if [ $contador -eq 3 ] then
    continue # salta la iteración cuando es 3
  fi
  echo "Contando: $contador"
  if [ $contador -eq 5 ]; then
    break # sale del bucle cuando llega a 5
  fi
done
```

#### while true (do while)

El bucle `do while` ejecuta un bloque de código mientras una condición se
cumpla, pero garantiza al menos una ejecución. En `Shell-Script` no existe el
`do while`, en su lugar lo simulamos con un `while true`

Un equivalente a `do while` es:

```bash
while true then; do
  # acciones que se ejecutan al menos 1 vez
  # evaluación de la condición

  if [ condicion ]; then
    break
  fi
done
```
