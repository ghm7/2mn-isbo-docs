# Particiones

- Primaria
- Lógica
- Extendida

Formatos mas populares en una partición:

- Ext4
- Swap
- XFS
- NTFS
- Fat32
- Fat16

Cada partición debe tener un punto de montaje. Ese punto es el lugar exacto en donde se va a ubicar el enlace a esa partición de disco

Lo podemos instalar en dos lugares

/ -> raíz
/home -> raíz

## Configuración de red

`ip addr show`

- Interfaz `lo` comunicación interna -> 127...
- Interfaz `ethØ` tarjeta de red
- Interfaz `wlan` wifi

> [!NOTE]
>
> Interfaz es una capa de abstracción

- `ifconfig` -> devuelve interfaces lo, ethØ, wlan

> [!NOTE]
>
> Instalar en caso de que la maquina no traiga `ifconfig`
>
> ```bash
> sudo apt update
> sudo apt install net-tools
> ```

- `ping` -> verifica si alcanzamos una dirección hosts
- `traceroute` -> rastrea la ruta de paquetes
- `telnet` -> establece conexión a un determinado puerto https
- `wget` -> descarga el contenido de una página

activar: `sudo ip link set <interfaz> up down`

## Ejercicio 1

- Ajustar la resolución de pantalla a una diferente que se este utilizando.

### Solución

- Desktop: Mate
- Vamos al a barra de tareas, la parte superior izquierda y clickeamos en el botón `Sistema > Preferencias > Hardware > Pantallas`.
- Cambiamos la resolución de `1280x800` a `800x600`
- Luego clickeamos `Aplicar`
- Aparece una ventana de confirmación y damos al botón `Mantener esta configuración`

# Repositorio

Un repositorio en Linux es un servidor o ubicación en linea donde se almacenan paquetes de software, bibliotecas y herramientas para tu distribución. La familia Debian tiene sus propios repositorios y se gestionan con `apt`, en Fedora con la herramienta `yum`.

## Agregar manualmente los repositorios en Debian

- `su - <Enter>`
- `nano /etc/apt/sources.list`
- Agregamos dentro del archivo `deb https://deb.debian.org/debian trixie main`

## Agregar usuario a sudo

- `su - <Enter>`
- `sudo visudo <Enter>`
- Vamos a donde este `root` y ponemos los mismos valores que en root pero para nuestro usuario

```bash
# User privilege specification
root ALL=(ALL:ALL) ALL
user ALL=(ALL:ALL) ALL
```
