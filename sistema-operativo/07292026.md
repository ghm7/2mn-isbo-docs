## Operadores de redireccionamiento en GNU/Linux

Cuando hablamos de operadores de redireccionamiento hacemos referencia a
aquellos operadores que permiten controlar el flujo de datos de entrada y salida
en la terminal. Usamos la linea de comandos para redirigir la salida de datos
(stdout) o la entrada (stdin) hacia archivos, dispositivos o incluso otros
comandos.

### Operadores

- `><` redireccion entrada o salida
- `>>` redireccion de salida
- `|` pipe (tuberia)
- `&` ejecucion en segundo plano
- `2>` redireccion de `sterr`
- `&>` redireccion de `stdout y stderr`

### Ejemplos

- `ls /noexiste 2> error.txt` redirige la salida de error a `error.txt`
- `ls /etc &> todo.txt` redirige `stderr` y `stdout`
- `echo "hola" > archivo.txt` redirecciona salida estandar a un archivo llamado
  `archivo.txt` y sobreescribe el contenido en caso de existir
- `cat < archivo.txt` redirecciona la salida de un comando desde un archivo
- `echo "nueva linea" >> archivo.txt` redireccionamiento y añade una nueva linea
  sin sobreescribir
- `ls | grep txt` envia la salida de un comando como entrada de otro. Filtra los
  txt

```bash
#!/bin/bash

echo "==Alta de usuario=="
echo "Script ejecutado por"

whoami
echo "En la fecha y hora de ejecucion"

date
echo "Ingrese el nombre del nuevo usuario"

read usuario

# Crear el usuario y su directorio home
sudo adduser -m "$usuario"
echo "Usuario $usuario creado con su directorio home"

# Asignar contraseña
echo "Informacion del usuario creado:"

id "$usuario"

# Registrar quién se logueo y cuándo se creó el usuario
echo "$(whoami) creo al usuario $usuario el $(date)" >> altausuario.log
echo "====="
echo "el script ha terminado"
```

## Ejercicio 0

Usa un comando en bash con el operador `>` para almacenar la lista del
directorio actual en un archivo llamado `lista.txt`. Despues con `cat` lee el
contenido del archivo.

### Solucion

```bash
ls > lista.txt
cat lista.txt
```

## Ejercicio 1

Crea un archivo de texto llamado `entrada.txt` con un mensaje corto usando el
operador `>`. Luego, utiliza el operador `<` en un comando para leer el
contenido en`entrada.txt` y pasarlo a comando `wc -l` para contar la linea del
archivo

El comando `wc(word count)` en `Bash` es una herramienta que cuenta lineas,
palabras y caracteres en archivos o entradas estandar.

`wc -l` (cuenta lineas), `wc -w` (cuenta palabras), y por su parte `wc -m`
(cuenta caracteres)
