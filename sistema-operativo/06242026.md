## Ejercicio 1

Crea un directorio llamado `pruebita` en tu directorio home y lista sus permisos
para identificar los valore predeterminados.

Pista: consultar `man ls` para verificar las opciones

```bash
mkdir ~/pruebita
ls -id ~/pruebita
    l -> formato de lista larga
    d -> lista directorio y no contenido
```

Cambiar al directorio `pruebita` los permisos utilizando notación numérica, los
cambios pueden ser para el propietario permisos totales, el grupo solo lectura,
y otros ningún permiso

```bash
chmod 740 ~/pruebita
```

## Ejercicio 2

Cambiar permisos y propietarios de un archivo

Crear el archivo `notas.txt` en el directorio `pruebita` cambiar sus permisos
para que el propietario y el grupo tengan permisos de lectura y escritura, pero
otros solo tengan lectura. Luego, cambia el propietario del archivo a un usuario
llamado `Ana` y el grupo a `estudiantes`

```bash
touch ~/pruebita/notas.txt
chmod 664 ~/pruebita/notas.txt
sudo grupoadd estudiantes
sudo useradd -m -G estudiantes ana
sudo chown ana:estudiante ~/pruebita/notas.txt
```

## Ejercicio 3

Dentro de mi directorio de trabajo, creamos un directorio llamado `proyectos` y
dentro del 2 archivos (`tarea1.txt`, `tarea2.txt`). Cambiar los permisos del
directorio `proyecto` y todo su contenido para que el propietario tenga permisos
completos, el grupo lectura y ejecución, y otros ningún permiso. Luego, cambia
el propietario de `proyecto` y todo su contenido a un usuario llamado `carlos` y
al grupo `desarrolladores`.

```bash
mkdir ~/proyecto
touch ~/proyecto/{tarea1.txt,tarea2.txt}
chmod 750 ~/proyecto
sudo groupadd desarrolladores
sudo useradd -m -G desarrolladores carlos
sudo chown -R carlos:desarrolladores ~/proyecto
```

## Ejercicio 4

Ver video de Permisos Linux <https://www.youtube.com/watch?v=NYSTdZP4Feo>

1. Según el video ¿Quién es el dueño del archivo?
2. ¿Qué sucede cuando se crea un nuevo usuario en el sistema?
3. ¿QUé significa x r w en el sistema de permisos de Linux?
4. ¿Con los permisos 664 qué tipo de permisos obtienen?

### Respuestas

1. El que crea el archivo es el dueño del mismo por defecto
2. Cuando se crea un usuario nuevo también se crea un grupo con el mismo nombre
   que el usuario
3. `x` - permiso de ejecución, `w` - permiso de escritura, `r` - permiso de
   lectura, si están los tres significa que tiene permisos totales
4. lectura y escritura en propietario y grupos y lectura en invitados

## Automatización de tareas y script

Los scripts son componentes potentes para gestionar soluciones y tareas.

Que quiere decir esto? Los scripts pueden ser osluciones eficientes para tareas
repetitivas en un tiempo breve.

Como escribimos script para ser usados en `Bash`?

- Utilizamos cualquier editor de **texto plano** tal como: `nano`, `pluma`,
  `gedit`, `leftpad`, y `xpad`
- Sería recomendable en la primera línea agregar: `#!/bin/bash`

`#!` A esta expresión en los sistemas basados en Unix se le reconoce con el
nombre de: `Shebang`. Sirve para indicar a continuación de ella la ruta
intérprete que utilizará el script: `/bin/bash`

- Una vez redactado nuestro script le guardamos con la extensión `sh` y la
  asignamos permisos de ejecución.

Ejemplo: `script.sh` Para ejecutarlo:

```bash
bash script.sh -> propietario no necesita permisos
./script.sh -> necesito permisos
source script.sh -> no abre subprocesos, lo lee directamente desde el archivo
```
