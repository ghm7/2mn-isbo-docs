# Qué es un repositorio?

Los sistemas Linux acceden a estos repositorios para descargar/instalar y actualizar
software de manera centralizada y segura, utilizando gestiores de paquetes como
APT (familia Debian) y yum/dnf (de la familia Fedora)

> [!NOTE]
>
> nano /etc/apt/sources.list
>
> directorio raíz en Linux es "/"

## Actualización y gestión de paquetes

### Debian

Actualizar paquetes

- sudo apt update

Actualizar programas

- sudo apt upgrade

Instalar programas

- sudo apt install firefox

Eliminar programas

- sudo apt remove firefox

Buscar paquetes

- sudo search nombre_paquetes

### Arch Linux

Actualizar sistema completo

- sudo pacman -Syu

Instalar un programa

- sudo pacman -S vim

Eliminar un programa

- sudo pacman -R vim

Buscar un paquete

- sudo -Ss nombre_paquete

### Fedora/Red Hat

Actualizar el sistema

- sudo dnf update

Instalar un programa

- sudo dnf install htop

Buscar un paquete

- dnf search nombre_paquete

### Open Suse

Instalar un programa

- sudo zypper install vim

Remover un programa

- sudo zypper remove vim

Actualizar el sistema

- sudo zypper update

Buscar paquete

- sudo zypper search vim

## Repositorios externos

Un repositorio externo es una fuente de software que no viene incluida por
defecto en tu distribución Linux

- flatpak
- snap
- appimage

Para instalar flatpak podemos consultar su documentación oficial
`https://flatpak/setup`

```bash
apt install flatpak

flatpak install aplicacion-id

flatpak run aplicacion-id
```

1. ¿Por qué no puede instalar la aplicación Telegram?
2. ¿Qué significa 'PPA'?
3. ¿Qué sucede si instalo Telegram, pero sin configurar un repositorio?
4. ¿Qué sucede si hago esto? apt update
5. ¿En el caso de hacer dpkg -i telegram.deb qué sucede?

### Respuestas

1. Porque el paquete no se encuentra registrado entre los repositorios de apt

3. No vamos a poder actualizarlo cuando el repositorio tenga nuevas versiones

   repositorio

   extra que no venga en el package, entonces va a instalar lo necesario

## Permisos

### Configuración de usuarios y permisos

A qué asistimos a la gestión de cuentas de usuarios y los privilegios asociados
a cada uno en un sistema GNU/Linux. Esto implica la creación, modificación y
eliminación de usuarios y grupos, así como la asignación de permisos para
controlar el acceso a archivos, directorios, y recursos del sistema, los usuarios
pueden ser administradores (root) o estándar y cada uno tiene un nivel de acceso
específico para garantizar la seguridad y organización del sistema.

Los permisos se gestionan mediante tres categorías: propietario, grupo y otros y
se definen con lectura (r), escritura (w), ejecución (x)

Los archivos tienen propietarios, estos propietarios tienen permisos (r,w,x),
luego tenemos los grupos que por defecto tienen (r,-,x) y luego hay otros
usuarios que vienen (r,-,-)
