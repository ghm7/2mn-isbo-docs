# Hoja de formulas - Escrito Matematicas CTS

Temas: desarrollar, factorizar, operatoria, ecuaciones de 1er grado y ecuaciones de 2do grado.

## Formulas

| Tema | Formula / idea |
| ---- | -------------- |
| Conmutativa | $a+b=b+a$ ; $ab=ba$ |
| Asociativa | $(a+b)+c=a+(b+c)$ ; $(ab)c=a(bc)$ |
| Neutro e inverso | $a+0=a$ ; $a\cdot1=a$ ; $a\cdot\frac{1}{a}=1,\ a\ne0$ |
| Distributiva | $a(b+c)=ab+ac$ ; al reves: $ab+ac=a(b+c)$ |
| Potencias | $x^m\cdot x^n=x^{m+n}$ ; $a^n\cdot b^n=(ab)^n$ |
| Parentesis | $(-2)^2=4$ pero $-2^2=-4$ ; $(3x)^2=9x^2$ pero $3x^2\ne9x^2$ |
| Cuadrado de suma | $(a+b)^2=a^2+2ab+b^2$ |
| Cuadrado de resta | $(a-b)^2=a^2-2ab+b^2$ |
| Binomios conjugados | $(a+b)(a-b)=a^2-b^2$ ; $k(a+b)(a-b)=ka^2-kb^2$ |
| Factor comun | $ab+ac=a(b+c)$ ; $mx^2+nx=x(mx+n)$ |
| Diferencia de cuadrados | $a^2-b^2=(a+b)(a-b)$ |
| Trinomio cuadrado perfecto | $a^2+2ab+b^2=(a+b)^2$ ; $a^2-2ab+b^2=(a-b)^2$ |
| Producto nulo | $A\cdot B=0 \Longleftrightarrow A=0\ \vee\ B=0$ |
| 1er grado | $ax+b=0 \Longleftrightarrow x=-\frac{b}{a},\ a\ne0$ |
| 2do incompleta sin $x$ | $ax^2+c=0 \Longleftrightarrow x^2=-\frac{c}{a}$ |
| 2do incompleta sin termino independiente | $ax^2+bx=0 \Longleftrightarrow x(ax+b)=0 \Longleftrightarrow x=0\ \vee\ x=-\frac{b}{a}$ |
| Bhaskara | $ax^2+bx+c=0$ ; $\Delta=b^2-4ac$ ; $x=\frac{-b\pm\sqrt{\Delta}}{2a}$ |

## Ejemplos rapidos

| Tipo | Desarrollo |
| ---- | ---------- |
| Binomios conjugados | $(3x+2)(3x-2)=(3x)^2-2^2=9x^2-4$ |
| Desarrollar y factorizar | $(x+5)^2-(x-3)^2$<br>$=x^2+10x+25-(x^2-6x+9)$<br>$=16x+16=16(x+1)$ |
| 2do incompleta | $35x^2+25x=0$<br>$5x(7x+5)=0$<br>$5x=0\ \vee\ 7x+5=0$<br>$x=0\ \vee\ x=-\frac{5}{7}$<br>$S=\left\{-\frac{5}{7},0\right\}$ |
| Bhaskara | $x^2-4x+3=0$<br>$a=1,\ b=-4,\ c=3$<br>$\Delta=(-4)^2-4\cdot1\cdot3=4$<br>$x=\frac{4\pm\sqrt4}{2}=\frac{4\pm2}{2}$<br>$S=\{1,3\}$ |
| Factorizacion verificada | $x^2-4x+3=(x-1)(x-3)$ |

## Recordar

- Desarrollado: tiene dos o mas terminos.
- Factorizado: queda escrito como producto de factores.
- Si factorizas para resolver, despues iguala cada factor a cero.
