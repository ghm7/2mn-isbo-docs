# Empezamos capa 2 - Enlace

- Preámbulo - 7 byte
- Inicio - 1 byte
- Mac Destino - 8 bytes
- Mac Origen - 6 bytes
- Tipo de trama - 2 bytes
- Dato - de 64 bytes a 1500 bytes
- Código de redundancia cíclica - 4 bytes
  > [!NOTE]
  >
  > También se conoce como check-sum que es una suma que se hace cuando empieza
  > el envío de datos y cuando llega se hace otra vez la cuenta y se corrobora
  > que sea el mismo valor, de esta forma se puede garantizar que no se dañaron
  > los datos
- GAP - 12 bytes - Espacio entre rama y rama
