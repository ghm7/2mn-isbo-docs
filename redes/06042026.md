# Crear VLAN

## Configurar switch

- Creamos un switch
- Seguimos estos pasos para configurar 2 vlan

```text
Switch>enable
Switch#config t
Enter configuration commands, one per line.  End with CNTL/Z.
Switch(config)#no ip domain-lookup
Switch(config)#vlan 10
Switch(config-vlan)#name alumnos
Switch(config-vlan)#exit
Switch(config)#vlan 20
Switch(config-vlan)#name profesores
Switch(config-vlan)#exit
Switch(config)#interface range fastEthernet 0/3-9
Switch(config-if-range)#switchport access vlan 10
Switch(config-if-range)#exit
Switch(config)#interface range fastEthernet 0/10-15
Switch(config-if-range)#switchport mode access
Switch(config-if-range)#switchport access vlan 20
Switch(config-if-range)#exit
Switch(config)#interface range fastEthernet 0/1-2
Switch(config-if-range)#switchport trunk allowed vlan 10,20
Switch(config-if-range)#end
Switch#
%SYS-5-CONFIG_I: Configured from console by console
write <--- Importante
Building configuration...
[OK]

```

Luego creamos maquinas y les agregamos IP, 6 maquinas con 3 van a ir para vlan
10 y 3 para vlan 20, seguimos esta convención 192.168.10.x para vlan 10 y
192.168.20.x para vlan 20

Verificamos encapsulamiento entre vlan a través del ping

Duplicamos todo lo que tenemos teniendo dos switches con 2 vlan cada uno,
recordar cambiar ips, se usan 192.168.10.10x y 192.168.20.10x
