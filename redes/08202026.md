## Mascara de Subred Variable - VSM

### Ejercicios

- 10.0.0.0/24 -> 1(100), 2(50), 3(14)

| Subred           | Broadcast     |
| ---------------- | ------------- |
| 1- 10.0.0.0/25   | 10.0.0.127/25 |
| 2- 10.0.0.128/26 | 10.0.0.19/26  |
| 3- 10.0.0.192/28 | 10.0.0.207/28 |

Para hacer subredes de mascara variable comienzo por la mayor hasta la menor
cantidad de equipos, siendo la siguiente subred uno más que el broadcast que el
anterior y ajustando a ella la mascara según la cantidad de equipos solicitados

Hay que sumarle uno al broadcast del anterior y ajustar la mascara

### Ejercicio 2

Dada una IP clase C privada determinar dos subredes de 60 equipos, dos de 10
equipos y una de 30 equipos

#### Redes

- 60 equipos
- 60 equipos
- 30 equipos
- 10 equipos
- 10 equipos

Necesitamos 60 equipos entonces hacemos 2^6 = 64 por lo tanto sobran 4, es
importante que sobre a que falte, aplicamos la ecuación `32-M=(bits de host)` <-
en este caso bits de host son 6, resultado `32-6=26`

| Subred             | Broadcast          |
| ------------------ | ------------------ |
| 192.168.1.0.0/26   | 192.168.1.0.63/26  |
| 192.168.1.0.64/26  | 192.168.1.0.127/26 |
| 192.168.1.0.128/27 | 192.168.1.0.159/27 |
| 192.168.1.0.160/28 | 192.168.1.0.175/28 |
| 192.168.1.0.176/28 | 192.168.1.0.191/28 |
