# Direccionamiento IP

Es el estado de 4 bytes que generan la dirección de los equipos que están en red

Una mascara limita el `campo de host`, es una serie de bytes que utilizo para
individualizar el equipo

192.168.10.0 <- este ultimo grupo es el que se utiliza para individualizar el
equipo 255.255.255.0

Por ejemplo 10.0.0.129/28

255.255.255.240 porque son grupos de 8 bytes

00001010.00000000.00000000.10000001 <- red (10.0.0.129/28)

00001010.00000000.00000000.10001111 <- broadcast (10.0.0.143/28)

11111111.11111111.11111111.11110000 <- mascara

El primer host del rango va a ser `red + 1` porque no podemos asignar un equipo
a la red que tenga el mismo valor de la red, tiene que ser uno mas

El ultimo equipo del rango va a ser `broadcast - 1` porque no podemos asignar un
equipo posterior al broadcast, es físicamente y matemáticamente imposible

> [!NOTE]
>
> formula correcta 2^(32-M) - 2, corregir debajo

Para saber la cantidad de direcciones es 32 - (cantidad de bytes en 1 que tiene
la mascara) = cantidad de direcciones

En este ejemplo podemos decir 32 - 28 = 4

## Clases

Las clases definen la cantidad de rango de redes

- Clase A de la 1.0.0.0 -> 127.255.255.255/8 (10.x.x.x)
- Clase B de la 128.0.0.0 -> 192.255.255.255/16 (172.16.x.x >>> 172.31.x.x)
- Clase C de la 192.0.0.0 -> 233.255.255.255/24 (192.168.x.x)

Clase privada es interna, dentro de una red, no sirve para transitar por la red

Clase publica es la red que puede transitar por internet

Podemos tener una red interna y navegar dentro de esa red pero al momento de
navegar hacia afuera, pasaríamos a utilizar una red o IP publica

## Ejercicios

Determinar `red`, `broadcast`, `rango`, `mascara décimal`, `tipo` y `clase`

- Paso 1: Determinar el octeto que es cortado por la máscara y pasarlo a binario
  (o sea el ultimo grupo de bytes, el del campo de host)
- Paso 2: Pasar todos los bytes de host a cero y determinar dirección de red
- Paso 3: Pasar todos los bytes de host a uno y determinar dirección de
  broadcast
- Paso 4: Rango = red + 1 >>> primer host, broadcast - 1 >>> ultimo host
- Paso 5: Cantidad de direcciones, 2^(32-M) - 2
- Paso 6: Máscara decimal es pasar los bytes de unos y pasarlos a decimal
