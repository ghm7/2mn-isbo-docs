# Pasaje a tablas - Agregación y Categorización

> [!NOTE]
>
> Las relaciones N a N siempre van a generar tabla.
>
> Siempre que agregamos una clave foránea, siempre especificar de donde vienen

## Categorías con atributos y/o relaciones

- Persona (<u>CI</u>, nombre, apellido)
- Estudiante (<u>CI</u>, fecha de nacimiento, telefono) CI -> Persona
- Adscripta (<u>CI</u>, email) CI -> Persona
- Docente (<u>CI</u>, grado) -> Persona

## Categorías sin atributos ni relaciones

- Grupo (<u>idG</u>, nombre, turno, CI) CI -> Adscripta
- Materia (<u>idM</u>, nombre, tipo)

- tiene (<u>idG</u>, <u>idM</u>) idG -> Grupo, idM -> Materia
- dicta (<u>idG</u>, <u>idM</u>, CI) CI -> Docente, idG, idM -> tiene
- cursa (<u>idG</u>, <u>idM</u>, <u>CI</u>, N de lista), idG, idM -> tiene, CI
  -> Estudiante

## Ejercicio 10 (reference: 05252026_2026_IBD_Ejercicio10.pdf)

- Persona (<u>CI</u>, nombre, apellido, Fecha de nacimiento, sexo)
- Estudiante (<u>CI</u>, idInsc) CI -> Persona, idInsc -> Inscripto
- Docente (<u>CI</u>) CI -> Persona
- Libreta (<u>idLib</u>, CI, nomGrupo, idM, año) CI -> Docente, nomGrupo ->
  Grupo, idM -> Materia
- Promedio (<u>idPromedio</u>, CI, idLib, periodo, nota, faltas) CI ->
  Estudiante, idLib -> Libreta
- Grupo (<u>nomGrupo</u>, turno)
- Materia (<u>idM</u>, nombre, año)
- Examen (<u>idExamen</u>, idM, fecha, periodo) idM -> Materia
- Inscripto (<u>idInsc</u>, <u>idExamen</u>, <u>CI</u>, nota, escrito) idExamen
  -> Examen, CI -> Estudiante
- cursa (<u>idLib</u>, <u>CI</u>, N° Lista) CI -> Persona
- tiene (<u>nomGrupo</u>, <u>idM</u>) nomGrupo -> Grupo, idM -> Materia

> [!NOTE]
>
> Cuando hay una agregación y debemos definir una llave foránea, la misma se
> define por la relación que haya en esa agregación
>
> Las agregaciones solo pueden contener una relación
