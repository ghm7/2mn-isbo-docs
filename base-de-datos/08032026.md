## Modelo físico

- Lenguajes
  - DDL: Administrar estructuras
  - DML: Administrar datos
  - SQL: Consultar datos
- Sentencias
  - CREATE: crear
  - ALTER: modificar
  - DROP: borrar

## Herramientas

- XAMPP Control Panel
  - MySQL >>> Start
- MySQL Workbench
  - MySQL Connections + Solo el nombre

```SQL
-- Crear una BD
CREATE DATABASE miBD;

-- seleccionar una BD
USE miBD;

-- crear una tabla
CREATE TABLE tablita (
  ci INT,
  nombre VARCHAR(15),
  apellido VARCHAR(20),
  fnac DATE,
  PRIMARY KEY(ci)
);

-- ingresar filas (DML)
INSERT INTO tablita VALUES(1234567, 'Fulano', 'de Tal', '2001-01-31');
INSERT INTO tablita VALUES(2345678, 'Elsa', 'Pato', '2003-02-21');
INSERT INTO tablita VALUES(3456789, 'Ben', 'Once', '2011-11-11');

-- ver datos (SQL)
SELECT * FROM tablita;
```

## Caracteres

- CHAR: fija
- VARCHAR: variable
- ENUM ("valor1", "valor2", "valor3"): permite guardar un solo valor
- SET ("valor1", "valor2", "valor3"): permite guardar un conjunto de valores
