# Pasaje a tablas ejercicio 11 (referencia 06012026_2026_IDB_Ejercicio11_ER.pdf)

- Estadio (<u>idE</u>, nombre, capacidad)
- Partido (<u>idP</u>, fecha, tipo, resultado {gol_local, gol_visita}, idE,
  idsel, local, visita) idE -> Estadio, idsel -> Seleccion, local -> juega,
  visita -> juega
- Gol (<u>idgol</u>, minuto, tipo, idsel, numero, idP) idsel -> Seleccion,
  numero -> Jugador, idP -> Partido
- Jugador (<u>idsel</u>, <u>numero</u>, nombre, fnac, posicion, altura)
- Seleccion (<u>idsel</u>, nombre, grupo, confederacion)
- juega (<u>local</u>, <u>visita</u>) local -> Seleccion, visita -> Seleccion
