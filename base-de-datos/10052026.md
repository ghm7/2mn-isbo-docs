## Ejercicio N 19 - SQL básico

- `SELECT`: atributo(s) a seleccionar
- `FROM`: tabla(s) a utilizar
- `WHERE`: condición que deben cumplir las filas
- `GROUP BY`: crea agrupaciones de datos
- `HAVING`: condición que deben cumplir las agrupaciones
- `ORDER BY`: criterio para ordenar
- `LIMIT`: limitar filas a seleccionar

## Solución

```sql
-- A) Mostrar todos los datos de los estadios. Ordenar por capacidad de mayor a menor
SELECT * FROM estadio ORDER BY capacidad desc;

-- B) Mostrar el nombre de la camiseta y la altura de los 15 jugadores más altos del mundial.
SELECT camiseta, altura FROM jugador ORDER BY altura desc LIMIT 15;

-- C) Mostrar el nombre y el club de los jugadores que juegan en la posición "delantero".
SELECT nombre, club FROM jugador WHERE posicion = "delantero";

-- D) Mostrar el número, el nombre de la camiseta, club y posición de los jugadores que juegan en clubes de Alemania (GER).
SELECT numero, camiseta, club, posicion FROM jugador WHERE club like "%(GER)%";

-- E) Mostrar la fecha y el resultado de todos los partidos del tipo "grupo". Ordenar por fecha.
SELECT fecha, gol_local, gol_visita FROM partido WHERE tipo = "grupo" ORDER BY fecha;

-- F) Mostrar el nombre de la camiseta, club y posición del los jugadores que tiene la camiseta 9, 10 o 11 de todas las selecciones.
-- Ordenar por nombre de la camiseta.
SELECT camiseta, club, posicion, numero FROM jugador WHERE numero = "9" OR numero = "10" OR numero = "11" ORDER BY camiseta;

-- G) Mostrar la cantidad de jugadores y el promedio de altura por posición (posición, cantidad, promedio).
SELECT posicion, COUNT(*) cantidad, AVG(altura) promedio from jugador GROUP BY posicion;

-- H) Mostrar el total y el promedio de los goles en todos los partidos del mundial.
SELECT SUM(gol_local + gol_visita) Goles, AVG(gol_local + gol_visita) Promedio FROM partido;

-- I) Mostrar la cantidad de jugadores por club (club, cantidad). Solo los primeros 20 clubes
-- con más jugadores.
SELECT club Club, count(*) Cantidad FROM jugador GROUP BY club LIMIT 20;

-- J) Mostrar la cantidad de equipos por confederación (confederación, cantidad)
SELECT confederacion, count(*) cantidad FROM seleccion GROUP BY confederacion;

-- K) Mostrar el total y el promedio de los goles para cada tipo de partido del
-- mundial(tipo, total, promedio). Ordenar por promedio de menor a mayor
SELECT tipo, SUM(gol_local + gol_visita) total, AVG(gol_local + gol_visita) promedio FROM partido GROUP BY tipo ORDER BY promedio;
```

## Producto cartesiano (AxB)

- Es el resultado de combinar cada fila de la tabla "A" con cada fila de la
  tabla "B"

### Gráficamente

### A

| ID  | Nombre |
| --- | ------ |
| 1   | Arroz  |
| 3   | Harina |
| 5   | Yerba  |

### B

| ID  | Total |
| --- | ----- |
| 1   | 205   |
| 3   | 185   |

### A x B

| ID  | Nombre | ID  | Total |
| --- | ------ | --- | ----- |
| 1   | Arroz  | 1   | 205   |
| 1   | Arroz  | 3   | 185   |
| 3   | Harina | 1   | 205   |
| 3   | Harina | 3   | 185   |
| 5   | Yerba  | 1   | 205   |
| 5   | Yerba  | 3   | 185   |

### En SQL

```sql
SELECT * FROM A, B;
```

## Join (A U B)

- Reunión o unión de dos o más tablas a través de algún atributo en común (clave
  foránea)

### Gráficamente

| ID  | Nombre | ID  | Total |
| --- | ------ | --- | ----- |
| 1   | Arroz  | 1   | 205   |
| 3   | Harina | 3   | 185   |

### En SQL

```sql
SELECT * FROM A join B on A.ID = B.ID
```
