## Lenguajes

- D.D.L. -> Administrar estructuras de datos
- D.M.L. -> Administrar datos
- S.Q.L. -> Consultar datos

### D.D.L. (Lenguaje de definición de datos)

- Estructuras
  - D.B.
  - Tablas
- Sentencias
  - CREATE: crear

  - ALTER: modificar
  - DROP: borrar

#### CREATE

- Create una nueva B.D.

`CREATE DATABASE nombreBD;` -> crea una base de datos

- Crear una tabla

```sql
CREATE TABLE tablita (
  Ci INT,
  nombre VARCHAR(15),
  apellido VARCHAR(20),
  fechaNac DATE,
  PRIMARY KEY(Ci)
);
```

#### SHOW

- Muestra las base de datos

`SHOW DATABASES;`

- Muestra las tablas

`SHOW TABLES`

#### USE

- Define que base de datos se usa en el gestor de bases de datos

#### DESCRIBE

- Describe una tabla, muestra nombres de atributos y propiedades

```
DESC tablita;
DESCRIBE tablita;
```

### D.M.L

#### INSERT

- Agregar valores a las tablas

```sql
INSERT INTO tablita VALUES (1234567, "Fulano", "de Tal", "2001-05-21");
INSERT INTO tablita VALUES (2345689, "User", "Two", "1998-08-28");
```

## Tipos de datos

### Caracteristicas

- `CHAR` (largo) -> cadena de largo fijo
- `VARCHAR` (máximo) -> cadena de largo variable
- `ENUM` (valor1, valor2, valor3, ...) -> turno ENUM("Matutino", "Vespertino",
  "Nocturno")
  - Permiten definir una lista de valores posibles
  - Solo se puede seleccionar uno
- `SET` (valor1, valor2, valor3, ...) -> idioma SET("español", "inglés",
  "portugués")

### Numéricos

- Enteros
  - `TINYINT`: 1 byte - 2^8, ... 256 valores (-128 al 128)
  - `SMALLINT`: 2 bytes - 2^16 65536 valores
  - `MEDIUMINT`: 3 bytes - 2^24
  - `INT`: 4 bytes - 2^32
  - `BIGINT`: 8 bytes - 2^64

- Decimales
  - `DECIMAL(p,s)`:

- Punto flotantes
  - FLOAT
  - DOUBLE
