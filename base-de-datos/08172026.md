## Creamos la tabla grupo

```SQL
CREATE TABLE grupo (
  id INT UATO_INCREMENT,
  nombre CHAR(3),
  turno ENUM('matutino','vespertino','nocturno') DEFAULT 'nocturno'
  PRIMARY KEY(id)
  UNIQUE(nombre)
);
```

### AUTO_INCREMENT

- Auto incrementa un dígito cada vez que se agrega una nueva entrada
- Si se utiliza el "0" o se deja vacío entonces agrega un valor auto incremental
- Si se agrega cualquier otro numero entonces va a utilizar ese valor

### DEFAULT

- Define un valor default si ninguno es pasado a la hora de hacer el INSERT

### UNIQUE

- Permite definir el atributo primo (único) en una tabla

## Agregar el atributo "id" a tablita

```SQL
ALTER TABLE tablita ADD id INT;
```

### ALTER ADD

- Agregamos atributo add a la tabla 'tablita'

## Agregamos la clave foránea

```SQL
ALTER TABLE tablita ADD FOREIGN KEY(id)
REFERENCES group(id);
```

## DML

- Administrar datos de las tablas
- Sentencias:
  - INSERT: ingresar filas
  - UPDATE: modificar filas
  - DELETE: borrar filas

### Ingresar filas

1. Indicando un valor para cada atributo de la tabla
   `INSERT INTO grupo VALUES(0, '2MN', 'nocturno');`
2. Omitir valores y/o cambiar orden `INSERT INTO grupo(nombre) VALUES('2MN');`
3. Varias filas
   `INSERT INTO tablita (nombre, ci, id) VALUES ('Aaa', 1234, 1), ('Bbb', 2341, 2), ('Ccc', 3412, 1), ('Ddd', 4321, 1);`

### Modificar filas

1. Todas las filas `UPDATE tablita SET apellido='Diaz', fnac='2001-01-21'`;
2. Las filas que cumplen con una **condición**
   `UPDATE grupo SET turno='nocturno' WHERE id=5;`

> [!NOTE]
>
> con `SET sql_safe_updates=true;` no nos va a permitir actualizar sin el
> `WHERE`

### Borrar filas

1. Todas las filas `DELETE FROM tablita;`
2. Las filas que cumplen con una "condición" `DELETE FROM grupo WHERE id = 5;`
