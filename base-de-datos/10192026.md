## Join

Reunión o intersección de dos o más tablas a través de algún atributo en común
(clave foránea)

### Gráficamente

| idP | nombre | idD | idD | nombre     |
| --- | ------ | --- | --- | ---------- |
| 1   | Fulano | 10  | 10  | Montevideo |
| 2   | Pepe   | 11  | 11  | Canelones  |
| 3   | Maria  | 10  | 10  | Montevideo |

### En SQL

```SQL
SELECT * FROM persona JOIN departamento
ON persona.idD = departamento.idD;
```

## Ejercicio #20

```sql
-- 1
SELECT territorio.*, region.nombre FROM territorio JOIN region ON territorio.idreg = region.idreg
ORDER BY region.nombre;

-- 2
SELECT T.nombre, T.capital, R.nombre FROM territorio T JOIN region R ON T.idreg = R.idreg
WHERE T.poblacion > 1000 AND T.poblacion <= 50000000;

-- 3
SELECT T.nombre, T.capital FROM territorio T JOIN region R ON T.idreg = R.idreg WHERE R.nombre = "Africa";

-- 4
SELECT R.nombre, SUM(T.poblacion) poblacion_total, SUM(T.superficie) superficie_total FROM territorio T JOIN region R ON T.idreg = R.idreg GROUP BY R.nombre;

-- 5
SELECT R.nombre, SUM(T.poblacion) / SUM(T.superficie) densidad_total FROM territorio T JOIN region R ON T.idreg = R.idreg GROUP BY R.nombre;

-- 6
SELECT R.nombre, COUNT(*) cantidad_por_region FROM territorio T JOIN region R ON T.idreg = R.idreg GROUP BY R.nombre;

-- 7
SELECT T.nombre, T.capital, R.nombre
FROM territorio T JOIN region R ON T.idreg = R.idreg JOIN dependencia D
ON T.idreg = R.idreg AND idter = tiene;

-- 8
SELECT T.nombre, R.nombre region
FROM territorio T JOIN region R ON T.idreg = R.idreg JOIN independencia I
ON T.idreg = R.idreg AND T.idter = I.tiene ORDER BY R.nombre;

-- 9
SELECT T.nombre, COUNT(*) dependen
FROM territorio T JOIN dependencia D ON T.idter = D.de
GROUP BY T.nombre;

-- 10 -- SIN TERMINAR
SELECT T.nombre, T.nombre dependencia
FROM territorio T JOIN region R ON T.idter = R.idreg JOIN dependencia D ON T.idter = D.tiene;
```
